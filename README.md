# 🏦 RetentIO: AI-Powered Customer Retention Engine

![Python](https://img.shields.io/badge/Python-3.9%2B-blue)
![Streamlit](https://img.shields.io/badge/Streamlit-App-ff4b4b)
![AI](https://img.shields.io/badge/AI-Google%20Gemini-4285F4)
![Model](https://img.shields.io/badge/Model-LightGBM-green)

**RetentIO** is an end-to-end Data Science & AI solution designed for Fintech and Banking sectors. It transforms raw customer data into actionable insights by predicting churn, calculating Customer Lifetime Value (CLV), and generating hyper-personalized retention messages using Generative AI.

---

## 🚀 Key Features

* **Real-time Data Pipeline:** Automatically cleans raw data, computes RFM (Recency, Frequency, Monetary) scores, and segments customers in real-time.
* **Predictive Analytics:**
    * **Churn Prediction:** Uses **LightGBM** to predict the probability of a customer leaving.
    * **CLV Modeling:** Estimates future value based on balance and engagement history.
* **AI Decision Agent:** A rule-based engine combined with **Uplift Modeling** logic to determine the best strategy (e.g., *Retention VIP*, *Cross-sell*, *Do Not Disturb*).
* **Generative AI Integration:** Uses **Google Gemini 1.5 Flash** to draft personalized SMS/Zalo/Email content for each customer.
* **Interactive Dashboard:** A professional UI built with **Streamlit** and **Plotly** for visualizing risk and opportunities.

## 🛠️ Installation & Setup Guide

Follow these steps to set up the project on your local machine.

### 1\. Clone the Repository

Open your terminal and run:

```bash
git clone [https://github.com/YOUR_USERNAME/RetentIO.git](https://github.com/YOUR_USERNAME/RetentIO.git)
cd RetentIO
```

### 2\. Set up a Virtual Environment (Recommended)

It is best practice to use a virtual environment to manage dependencies.

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Mac/Linux
python3 -m venv venv
source venv/bin/activate
```

### 3\. Install Dependencies

Install all required libraries listed in `requirements.txt`:

```bash
pip install -r requirements.txt
```

### 4\. Configure Environment Variables

This project uses Google Gemini API. You need to set up your API key.

1.  Create a file named `.env` in the root directory.
2.  Add your API Key to the file:

<!-- end list -->

```env
GEMINI_API_KEY=your_google_api_key_here
```

*(Get your free key at [Google AI Studio](https://aistudio.google.com/))*

## 🧠 System Architecture

### 1\. Data Layer (`src/features.py`)

  - Ingests raw CSV data.
  - Handles missing values and data type conversion.
  - Performs Feature Engineering: Calculates **Recency**, **Tenure**, and assigns **RFM Segments**.

### 2\. Inference Layer (`src/inference.py`)

  - Loads the pre-trained `churn_lgbm.pkl` model.
  - Predicts **Churn Probability** for the selected customer.
  - Simulates **CLV** and **Uplift Score** based on business logic and predicted risk.

### 3\. Agent Layer (`src/agent.py`)

  - **Strategy Engine:** Decides the "Next Best Action" (e.g., if Churn Risk is High but Uplift is High -\> **Action: Save Customer**).
  - **GenAI Wrapper:** Sends a prompt with customer context to **Google Gemini API** to generate the final marketing message.
  - **Fallback Mechanism:** If the API fails (quota exceeded), it automatically switches to pre-defined templates to ensure the app never crashes.

## 📊 Dataset

The project uses a snapshot dataset of **80,000 bank customers** in Vietnam, which you can download it from the owner of this datasets: https://www.kaggle.com/datasets/tranhuunhan/vietnam-bank-churn-dataset-2025, containing:

  - **Demographics:** Age, Gender, Occupation, Location.
  - **Financials:** Balance, Credit Score, Monthly Income.
  - **Behavior:** Activity history, Service usage, Engagement score.
